MapMaker

Pick a seed and a resolution, adjust the world settings, then press Generate. The same seed and settings always give the same world; a low-resolution preview shows the same continents, mountains and climates as the full-resolution world. Settings changes take effect on the next Generate.

idle WebGL2 is not available in this browser, so the globe is disabled and the flat map is drawn on the CPU (slower, same results).
